# Ocean Blog — CRUD Web Application

A blog web application built using Node.js, Express.js, and EJS to practice backend development, Express routing, and CRUD operations.

## Features

- Create blog posts
- View existing posts
- Edit and update posts
- Delete posts
- Render dynamic pages using EJS templates
- Deployed on Vercel

## Tech Stack

- **Backend:** Node.js, Express.js
- **Templating:** EJS
- **Frontend:** HTML, CSS, JavaScript
- **Deployment:** Vercel

## Live Demo

[Visit Ocean Blog](https://ocean-blog-crud.vercel.app)

## Getting Started

Clone the repository:

```bash
git clone https://github.com/abed-al-rahmanM/ocean-blog-crud.git
cd ocean-blog-crud
```

Install dependencies:

```bash
npm install
```

Start the application using the command configured in `package.json`.
